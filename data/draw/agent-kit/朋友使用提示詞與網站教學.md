# 👾 抽獎助手｜朋友使用提示詞與網站教學

版本：2026-10-03c（c 版：三段提示詞合併為一段「開始提示詞」；b 版：加入好友並參加＝直接按、按到參加就打叉、網站按鈕改名「抽獎」；技能改為工具中立版，Codex 與 Claude 等具電腦操作能力的環境共用）

## 分享前先說清楚

這是操作流程技能，不會單憑文字提示就取得朋友手機的控制權。朋友的 AI 環境需要能讀取與操作其 Mac 的 iPhone 鏡像視窗，並具備必要權限；是否可用，以該環境實際工具為準。**推薦使用 Codex＋Computer Use**：本次實測環境就是 Mac、iPhone 鏡像與 Codex 的 Computer Use 工具，能跑可中斷的連續點擊迴圈，速度最快；Claude 等其他具本機電腦操作能力的環境可安裝同一份技能，但尚未實測，第一次務必先測 3 項。

只支援文字對話或只能操作遠端瀏覽器的環境，未必能操作本機 iPhone。不要在網站寫成「貼到任何 GPT 都能自動抽」。技能提供操作規則，控制工具才提供動作能力，兩者需一起具備。[官方技能說明](https://developers.openai.com/plugins/concepts/skills)

## 開始提示詞（一段搞定，推薦）

先把技能包下載到電腦（不用解壓縮），選好地區與店家，再把下面這段貼給有本機電腦操作能力的 AI。網站 👾 教學裡的「複製開始提示詞」就是這段，另外會在最後補上目前範圍、未抽筆數與技能包檔名。

> 請用 iphone-beyblade-draw 技能（還沒安裝就先裝）幫我處理戰鬥陀螺抽選目錄「目前篩選」的全部剩餘項目，不要更改範圍。以下步驟自己接著做，不必每一步回來問我：
>
> 1. 檢查：確認你有能看見並點擊本機 Mac「iPhone 鏡像輸出」視窗的工具。沒有就告訴我缺少哪項能力並停止，不要聲稱能操作。
> 2. 安裝：若還沒有這個技能，從我下載的技能包（檔名 iphone-beyblade-draw-版本.zip，通常在「下載項目」）安裝成你能使用的個人技能。
> 3. 試跑：確認畫面、篩選與按鈕位置後先處理 3 項。三項都正常就直接接著做；有異常就停下來回報。
> 4. 整批：開啟抽獎 → 點參加抽獎（寫「加入好友並參加抽獎」也直接按）→ 確定按到就打叉，不必確認結果 → 下一項。網站有 👾 Agent 模式就用單一品項介面。已明確顯示先前未中獎就直接關閉。
>
> 按鈕未出現時，先短暫等候，再用當前瀏覽器重整同一抽獎頁。未確認點到參加前，不關閉、不跳下一項。找不到重整入口、畫面不明或斷線時停止點擊並保留位置。
>
> 使用可中斷的連續迴圈，不要每 8 或 10 項停下等我；工具若必須分段，立即自動接續。我說「停止」時立刻停止。
>
> 最後確認目前篩選的未抽數量為 0，回報處理數及未完成項目。不要購買、付款、核銷，或把清單清空說成全部中獎。

安裝位置應依朋友使用的產品版本與技能載入設定決定，不複製作者的電腦路徑（例：Claude Code／Claude 桌面 App 的個人技能放在 `~/.claude/skills/iphone-beyblade-draw/SKILL.md`；Claude 另需先開啟 computer use，見技能檔附錄）。官方文件列出本機技能載入位置，也建議較廣泛的分發使用 plugin；本分享包目前是技能資料夾 ZIP，不是已上架的 plugin。[官方技能安裝與分發說明](https://learn.chatgpt.com/docs/build-skills)

朋友的畫面大小可能不同。首次需定位按鈕，不能直接照搬本次電腦的座標。Codex 中可用 `$iphone-beyblade-draw` 指名；其他支援技能的環境可直接寫完整技能名稱或從技能選單選取。

## 分步驟版（出問題時再用）

一段版卡住時，可以拆開一步一步來：

- 只檢查與安裝：「請檢查我提供的 iphone-beyblade-draw 技能包，並安裝成你能使用的個人技能。先確認你有能讀取與操作本機 Mac『iPhone 鏡像輸出』的工具；沒有就告訴我缺少哪項能力，不要聲稱能操作。完成後先不要抽獎，告訴我準備結果與技能名稱。」
- 只測 3 項：「請使用 iphone-beyblade-draw 技能，確認目前篩選和按鈕位置，先處理 3 項就停，回報實際處理數與異常。不要更改篩選、購買或核銷優惠券。」

## 停止與繼續

停止：

> 立即停止所有點擊，保留目前位置，等我說繼續。

繼續：

> 鏡像已恢復，請重新確認目前在清單還是抽獎頁，再從中斷位置繼續，避免漏按或重複跳項。

## 網站教學：首次點 👾 時顯示

### 標題

讓你的 AI 幫你逐項抽獎

### 說明

Agent 模式一次只顯示一個品項，操作位置固定。關閉官方抽獎頁回來後，會自動換下一項。

你需要先準備能控制本機畫面的 AI 工具；只有貼提示詞不會自動取得手機控制能力。

### 三步驟

1. **準備環境**：在 Mac 連接 iPhone 鏡像，並在手機完成 LINE 登入。
2. **下載技能包**：在電腦上下載，不用解壓縮，AI 會自己裝。
3. **開始處理**：選好地區與店家，複製開始提示詞貼給 AI。一段就夠：AI 會自己檢查工具、裝技能、先試 3 項，沒問題就接著跑完。操作時保持鏡像連線，避免同時點擊手機。

### 按鈕

- 下載技能包
- 複製開始提示詞
- 我知道了，進入 Agent 模式

### 常駐輕提示

「已點參加才關閉；按鈕沒出現先重整。說『停止』可隨時暫停助手。」

首次教學關閉後，不再遮住單品項畫面。教學可由 👾 旁的說明入口重新開啟；不在每一項彈出。

## 工程補充

- 開關僅切換網站介面，不代表 AI 已連線，也不會自動啟動電腦控制。
- 技能包與提示詞需有版本號；下載、教學與文件必須一致。
- 未完成部署的下載連結不能顯示可下載；此文件中的按鈕為設計規格。
- 複製開始提示詞時可帶入目前可見的地區、店家及筆數，並保留執行前確認；不放入登入憑證或私人裝置路徑。
- 新版 Agent 模式未上線前，顯示一般清單操作版提示，不宣稱已有返回自動下一項。
- 網站無法可靠偵測外部 AI 是否具有控制權，應讓 AI 自行檢查工具，不顯示假的「已連接 GPT」。
