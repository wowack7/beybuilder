# 👾 抽獎助手｜朋友使用提示詞與網站教學

版本：2026-10-03（技能改為工具中立版，Codex 與 Claude 等具電腦操作能力的環境共用）

## 分享前先說清楚

這是操作流程技能，不會單憑文字提示就取得朋友手機的控制權。朋友的 AI 環境需要能讀取與操作其 Mac 的 iPhone 鏡像視窗，並具備必要權限；是否可用，以該環境實際工具為準。本次實測環境是 Mac、iPhone 鏡像與 Codex 的 Computer Use 工具；Claude 等其他具本機電腦操作能力的環境可安裝同一份技能，但尚未實測，第一次務必先測 3 項。

只支援文字對話或只能操作遠端瀏覽器的環境，未必能操作本機 iPhone。不要在網站寫成「貼到任何 GPT 都能自動抽」。技能提供操作規則，控制工具才提供動作能力，兩者需一起具備。[官方技能說明](https://developers.openai.com/plugins/concepts/skills)

## 第一次使用：檢查環境並安裝

將分享包下載到電腦，交給有本機檔案存取能力的 AI。貼上：

> 請檢查我提供的 iphone-beyblade-draw 技能包，並安裝成你能使用的個人技能。先確認你有能讀取與操作本機 Mac「iPhone 鏡像輸出」的工具。如果沒有，請告訴我缺少哪項能力，不要聲稱能操作。完成安裝後先不要抽獎，告訴我準備結果與技能名稱。

安裝位置應依朋友使用的產品版本與技能載入設定決定，不複製作者的電腦路徑（例：Claude Code／Claude 桌面 App 的個人技能放在 `~/.claude/skills/iphone-beyblade-draw/SKILL.md`；Claude 另需先開啟 computer use，見技能檔附錄）。官方文件列出本機技能載入位置，也建議較廣泛的分發使用 plugin；本分享包目前是技能資料夾 ZIP，不是已上架的 plugin。[官方技能安裝與分發說明](https://learn.chatgpt.com/docs/build-skills)

## 第一次操作：先測三項

> 請使用 iphone-beyblade-draw 技能。我已連接 iPhone 鏡像、登入 LINE，並選好地區與店家。請確認目前篩選和按鈕位置，先測試 3 項：開啟抽籤頁，點「參加抽獎」，確認已觸發後只關閉抽獎彈窗，回來處理下一項。按鈕未出現時使用當前瀏覽器重整同一頁，不以關閉重開代替；找不到重整入口就停在該項說明。不要更改篩選、購買或核銷優惠券。完成後回報實際處理數與異常。

朋友的畫面大小可能不同。首次需定位按鈕，不能直接照搬本次電腦的座標。

## 已準備好：連續完成整批

Codex 中可用 `$iphone-beyblade-draw` 指名；其他支援技能的環境可直接寫完整技能名稱或從技能選單選取。

> 請使用 iphone-beyblade-draw 技能，處理目前篩選的全部剩餘項目，不要更改範圍。若網站已有 👾 Agent 模式，使用單一品項介面；若還是一般清單，依目前畫面操作，不假設新版已上線。
>
> 先確認畫面與按鈕位置，再連續執行：開啟抽籤 → 點參加抽獎 → 確認已觸發 → 確認仍是抽獎彈窗才打叉 → 下一項。不等中獎結果；已明確顯示先前未中獎就直接關閉。
>
> 按鈕未出現時，先短暫等候，再使用當前瀏覽器重整同一抽獎頁。未確認點到參加前，不關閉、不跳下一項。找不到重整入口、畫面不明或斷線時停止點擊並保留位置。
>
> 使用可中斷的連續迴圈，不要每 8 或 10 項停下等我指示。工具若必須分段，立即自動接續。減少模型往返與不必要的固定等待，但保留必要的畫面狀態確認。我說「停止」時立刻停止。
>
> 最後確認目前篩選的未抽數量為 0，並回報處理數及未完成項目。不要購買、付款、核銷，或把清單清空說成全部中獎。

## 停止與繼續

停止：

> 立即停止所有點擊，保留目前位置，等我說繼續。

繼續：

> 鏡像已恢復，請重新確認目前在清單還是抽獎頁，再從中斷位置繼續，避免漏按或重複跳項。

## 網站教學：首次點 👾 時顯示

### 標題

讓你的 AI 幫你逐項抽籤

### 說明

Agent 模式一次只顯示一個品項，操作位置固定。關閉官方抽獎頁回來後，會自動換下一項。

你需要先準備能控制本機畫面的 AI 工具；只有貼提示詞不會自動取得手機控制能力。

### 三步驟

1. **準備環境**：在 Mac 連接 iPhone 鏡像，並在手機完成 LINE 登入。
2. **準備助手**：下載技能，讓 AI 確認可以操作鏡像視窗。第一次先測 3 項。
3. **開始處理**：選好地區與店家，複製開始提示詞到 AI。操作時保持鏡像連線，避免同時點擊手機。

### 按鈕

- 下載技能包
- 複製環境檢查提示詞
- 複製測試 3 項提示詞
- 複製整批開始提示詞
- 我知道了，進入 Agent 模式

### 常駐輕提示

「已點參加才關閉；按鈕沒出現先重整。說『停止』可隨時暫停助手。」

首次教學關閉後，不再遮住單品項畫面。教學可由 👾 旁的說明入口重新開啟；不在每一項彈出。

## 工程補充

- 開關僅切換網站介面，不代表 AI 已連線，也不會自動啟動電腦控制。
- 技能包與提示詞需有版本號；下載、教學與文件必須一致。
- 未完成部署的下載連結不能顯示可下載；此文件中的按鈕為設計規格。
- 複製整批提示詞時可帶入目前可見的地區、店家及筆數，並保留執行前確認；不放入登入憑證或私人裝置路徑。
- 新版 Agent 模式未上線前，顯示一般清單操作版提示，不宣稱已有返回自動下一項。
- 網站無法可靠偵測外部 AI 是否具有控制權，應讓 AI 自行檢查工具，不顯示假的「已連接 GPT」。
